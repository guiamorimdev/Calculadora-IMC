# Calculadora de IMC 

Este é um projeto simples feito em **HTML, CSS e JavaScript** para calcular o IMC (Índice de Massa Corporal).

## 🔗 Acesse o site
https://guiamorimdev.github.io/Calculadora-IMC

## 🧮 Como funciona
1. Digite seu nome
2. Informe seu peso em Kg
3. Informe sua altura em metros
4. Clique no botão para calcular

O sistema mostra o valor do IMC.

## 👀 Observação:
* Digite os valores do peso e altura usando "." para separar casa decimal. Ex. Correto: 1.80, Ex. Errado: 1,80

- HTML
- CSS
- JavaScript
